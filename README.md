# برنامه هفتگی من

برنامه‌ی هفتگی فارسی (برنامه‌ی روزها، عادت‌ها، کارها، امتحان‌ها، آب، خواب، حال و…) با ذخیره‌ی ابری روی **JSONBin** و آماده‌ی **GitHub** و **Render**.

بدون سرور هم کار می‌کند (اطلاعات روی همان دستگاه می‌ماند). با سرور، اطلاعات بین گوشی و لپ‌تاپ همگام می‌شود.

## ۱) ساخت دیتابیس در JSONBin
1. در [jsonbin.io](https://jsonbin.io) حساب بساز و یک Bin جدید با محتوای `{}` بساز.
2. **Bin ID** را از آدرس Bin کپی کن.
3. از بخش API Keys مقدار **Master Key** را کپی کن.

## ۲) گذاشتن روی GitHub
```bash
git init
git add .
git commit -m "برنامه هفتگی من"
git branch -M main
git remote add origin https://github.com/USERNAME/my-weekly-planner.git
git push -u origin main
```
فایل `.env` در `.gitignore` است و هیچ‌وقت آپلود نمی‌شود. کلیدها را داخل کد نگذار.

## ۳) دیپلوی روی Render
1. در [render.com](https://render.com) گزینه‌ی **New → Blueprint** را بزن و مخزن گیت‌هاب را وصل کن (فایل `render.yaml` همه‌چیز را تنظیم می‌کند). یا **New → Web Service** با Build `npm install` و Start `npm start`.
2. این سه متغیر را در Environment بگذار:

| متغیر | مقدار |
|---|---|
| `JSONBIN_BIN_ID` | Bin ID |
| `JSONBIN_API_KEY` | Master Key |
| `ACCESS_KEY` | یک رمز دلخواه و طولانی (خودت می‌سازی) |

3. بعد از دیپلوی، سایت را باز کن. بار اول کلید `ACCESS_KEY` را می‌پرسد؛ همان را وارد کن. روی هر دستگاه یک‌بار لازم است.

## نحوه‌ی کار
- هر تغییری که بدهی، حدود ۱.۵ ثانیه بعد خودکار ذخیره می‌شود. دکمه‌ی پایین صفحه وضعیت را نشان می‌دهد: «همگام ✓»، «آفلاین» یا «کلید دسترسی لازم».
- آفلاین هم می‌توانی کار کنی؛ بعد از وصل شدن اینترنت ارسال می‌شود.
- اگر دو دستگاه همزمان تغییر بدهند، آخرین ذخیره‌شده می‌ماند.
- بار اول روی دستگاه که از قبل اطلاعات دارد و روی سرور هم اطلاعات هست، می‌پرسد کدام نگه داشته شود.
- رایگانِ JSONBin حدود ۱۰۰ کیلوبایت جا دارد؛ برای این برنامه کافی است.
- Render رایگان بعد از مدتی بی‌کاری می‌خوابد و اولین بازشدن چند ثانیه طول می‌کشد.

## اجرا روی کامپیوتر
```bash
npm install
cp .env.example .env   # مقدارها را پر کن
npm run dev            # نیاز به Node 20.6 یا بالاتر
```
سپس `http://localhost:3000` را باز کن.
