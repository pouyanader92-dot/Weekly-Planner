# برنامه هفتگی من

برنامه‌ی هفتگی فارسی با **ثبت‌نام و ورود**، حساب **مدیر** و **خانم زینب (معلم)**، ۸ تم مناسبتی، دستاوردها، رتبه‌بندی دوستانه و ذخیره‌ی ابری روی **JSONBin**؛ آماده‌ی **GitHub** و **Render**.

## نقش‌ها
- **کاربر:** برنامه‌ی شخصی خودش؛ پیام معلم بالای صفحه‌اش می‌آید؛ در رتبه‌بندی دوستانه است (می‌تواند نامش را مخفی کند).
- **خانم زینب (`zeynab`):** خلاصه‌ی پیشرفت همه‌ی دانش‌آموزها (امتیاز، عادت‌ها، کارها، مطالعه) و ارسال پیام کوتاه به هر نفر.
- **مدیر (`admin`):** همه‌ی کارهای بالا + ساخت رمز موقت، ارتقا به معلم یا برگشت به کاربر، حذف حساب و **تغییر تم سایت برای همه**.

هر کس می‌تواند «تغییر رمز» را از پایین صفحه بزند. هر کاربر هم می‌تواند تم شخصی خودش را انتخاب کند (پایین صفحه).

## ۱) JSONBin
1. در [jsonbin.io](https://jsonbin.io) یک Bin بساز. JSONBin اجازه‌ی Bin خالی نمی‌دهد، پس این را داخلش بگذار:
   ```json
   {"users": {}, "theme": "normal"}
   ```
2. **Bin ID** و **Master Key** را بردار.

## ۲) GitHub
```bash
git init && git add . && git commit -m "برنامه هفتگی من"
git branch -M main
git remote add origin https://github.com/USERNAME/my-weekly-planner.git
git push -u origin main
```

## ۳) Render
**New → Blueprint** و وصل کردن مخزن (از `render.yaml` استفاده می‌کند)، یا Web Service با Build `npm install` و Start `npm start`. این متغیرها را بگذار:

| متغیر | مقدار |
|---|---|
| `JSONBIN_BIN_ID` | Bin ID |
| `JSONBIN_API_KEY` | Master Key |
| `ADMIN_PASSWORD` | (اختیاری) رمز دلخواه برای حساب `admin` |
| `TEACHER_PASSWORD` | (اختیاری) رمز دلخواه برای حساب `zeynab` |
| `SESSION_SECRET` | (اختیاری) یک رشته‌ی تصادفی |

بدون هیچ تنظیم اضافه، رمزهای اولیه این‌هاست: مدیر `admin` با `Planner@Admin#2026` و خانم زینب `zeynab` با `Zeynab@Planner#2026` (داخل `server.js` نوشته شده‌اند). بعد از اولین ورود می‌توانی «تغییر رمز» را بزنی؛ رمزِ عوض‌شده با ری‌استارت برنمی‌گردد. اگر مخزن گیت‌هاب عمومی است، حتماً `ADMIN_PASSWORD` و `TEACHER_PASSWORD` را در Render بگذار تا رمزهای داخل کد بی‌اثر شوند.

## نکته‌ها
- اطلاعات هر کاربر خودکار ذخیره می‌شود و بین دستگاه‌ها همگام است؛ آفلاین هم کار می‌کند.
- هنگام خروج، اطلاعات حساب از همان دستگاه پاک می‌شود (روی سرور می‌ماند).
- ظرفیت رایگان JSONBin حدود ۱۰۰ کیلوبایت است: برای ده‌ها نفر کافی است ولی نه صدها.
- Render رایگان بعد از بی‌کاری می‌خوابد و اولین بازشدن چند ثانیه طول می‌کشد.

## اجرا روی کامپیوتر
```bash
npm install
cp .env.example .env   # مقدارها را پر کن
npm run dev            # Node 20.6 یا بالاتر
```
